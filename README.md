# 🎵 Minimal Music Player for C#

> 重构音乐播放器，功能与 Electron 版完全一致。  

---

## 📦 运行环境

- 需要 **.NET 10** 运行时  
  - 从 [微软官网](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) 下载，或点击右侧 **Releases** 下载 `windowsdesktop-runtime-10.0.10-win-x64.exe` 。

---

## 🚀 使用方法

播放器为**绿色免安装**，双击 `exe` 文件即可运行。

### 首次启动自动生成

- `bitmapimage/` 文件夹 —— 存放歌曲专辑封面（300 首歌曲约占 **5 MB**）
- `music.json` —— 存储音乐库信息

> 📌 **备注**：重新加载歌曲时，会自动刷新 `bitmapimage` 和 `music.json`。

## ❓ 常见问题

### 1. 内存占用升高（最高约 200 MB）如何解决？

- **方法**：切换歌曲，或重新打开播放器  

---

### 2. 替换新 `exe` 后，使用旧数据运行，内存占用变高？

- **尝试**：切换歌曲，或重新打开播放器  
- **若无效**：删除所有旧数据（`bitmapimage` 文件夹和 `music.json`），然后重新运行 `exe`，让程序重新生成缓存。
